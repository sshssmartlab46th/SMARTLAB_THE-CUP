# Persistent Project Rules & Instructions

- **Footer Credit**: Always use `made by SMARTLAB` (never include individual names like `김태호`). Keep it clean and subtle across all screens and components.
- **Admin Identity**: The System Administrator (총괄 관리자 / `sshsgym`) is NOT a teacher. Admins belong to the Event Headquarters (총괄본부), have `isTeacher: false`, and are distinct from teachers/faculty (who have ID format ending in `00` e.g., `10100`).
